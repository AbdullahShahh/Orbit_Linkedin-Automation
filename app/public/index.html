      How it works

      The recorded manual workflow that this app repeats for you.

      1. Create a Message Type – e.g. "Bookkeepers". Write the note. Use {first_name}, {company}, {title}. Separate alternative versions with a line containing ---; one is picked at random. [Hi|Hello] picks one word at random.
      2. Add a List – open your Sales Navigator Saved search (or lead list), copy the URL from the address bar, paste it here and pick the message type.
      3. Your own Chrome – keep LinkedIn / Sales Navigator open and logged in. The LinkedIn Connect Bot extension (badge shows ON) uses that tab. To pick a specific tab, open it and click the extension icon → Use this tab.
      4. Start sending – for each lead the bot opens the LinkedIn profile, clicks Connect (or More → Connect for 3rd-degree), Add a note, pastes the personalised message and clicks Send. Then it waits your configured delay (default 30–50 s).
      5. Already-connected and already-invited people are skipped automatically and never contacted twice.
