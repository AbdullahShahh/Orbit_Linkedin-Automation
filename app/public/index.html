        How it works

        Everything the bot does, and where to change it – no code needed.

        Setup

        • Chrome + extension – stay logged in to LinkedIn / Sales Navigator. The LinkedIn Bot extension must be ON (the dashboard shows Extension connected).
        • No extra window – the bot works in a collapsed "LinkedIn Bot" tab group in your Chrome window. Its tabs open in the background, never take focus, and close when a job is done. A tab showing linkedin.com/robots.txt is the bot's working tab – a tiny page the bot reads LinkedIn from. Don't close it during a run (if you do, the bot opens a new one).
        • After an extension update: chrome://extensions → reload LinkedIn Bot once.

        Connection campaigns

        1. Message Types – write the note. Use {first_name}, {company}, {title}. Separate alternative versions with a line containing --- (one is picked at random); [Hi|Hello] picks one word at random.
        2. Lists – paste a Sales Navigator saved search / lead list URL, pick the message type, optionally target countries and a send limit. Turn the list ON.
        3. Dashboard → Start sending – for each lead the bot opens the profile, clicks Connect (when Connect is hidden under More, it opens LinkedIn's own invite page instead), adds your note and sends. Then it waits your delay (Settings → Delays) and takes a longer break every N invitations.
        4. Skipped automatically: already connected, invitation already pending, email required, outside the list's target countries. A browser problem (tab closed, extension reloaded) never skips a lead – it stays in the queue and is tried again.
        5. Leads page – tabs Pending / Sent / Accepted / Skipped / Excluded, search, list filter and order. Don't contact blocks a person for good (even after a new sync, in any list); Undo puts them back. Delete only deletes – the person may come back on the next sync.
        6. Acceptances – every 10 minutes the extension reads LinkedIn's "recently added connections" list in the background (no tab, also during campaigns), so the Accepted number goes up within minutes. Check acceptances on the dashboard checks right now. A full scan of your Connections page still runs every few hours as a backup (Settings).

        Account safety (Settings → Account safety)

        • Daily limit, per-run limit and weekly limit (counted from Monday, when LinkedIn resets) – the bot stops sending at the first one reached.
        • Max pending invitations – no new invitations while too many are still waiting for an answer.
        • Low acceptance warning – shown on the dashboard when too few people accept.
        • Security check / restriction / "too many requests" – if LinkedIn shows a checkpoint, captcha or restriction page, the bot stops everything, turns campaigns OFF and pauses for the hours you set. Open LinkedIn yourself, solve any check, then press clear on the dashboard.
        • Sending hours and weekends – optional; 0–24 = any time.
        • The dashboard strip shows this week's count, pending invitations, acceptance rate and today's profile visits.
        • Lists are Active or Paused – only you change that, the bot never pauses a list. Each list's daily limit and the overall daily limit reset at midnight.
        • If LinkedIn's own weekly limit is hit, sending goes on hold for the whole account (lists stay Active). The hold clears itself on Monday, or press Resume sending.

        Prospect finder

        • Searches tab → + Job search / + Post search – build searches with filters, like Sales Navigator / Apollo. Each search is saved; every search that is ON runs when you press Run now, or press Run on one. Copy makes a variant, Edit changes it.
        • Job search filters: job titles × locations (each pair is one LinkedIn search), remote / hybrid / on-site, experience level, job type, posted (24 h / week), order, Easy Apply, fewer than 10 applicants, where you can apply from (anywhere in the world / anywhere in Europe / no rule), max years asked, skip jobs asking for another language, skip title words and companies, and switches for every rule (similar titles, SDR, senior roles, staffing companies, agency posts, non-sales roles, internships).
        • Post search filters: keywords (exact phrase or any word), author job titles, where the author lives, kind of post (asking for help / hiring), hiring posts must be remote, order, posts per keyword, what the post must be about (your topics + built-in lead gen topics), skip words, skip author headlines, and switches for every rule (must ask for something, about the topic, written by the buyer, skip sellers / job seekers / recruiters / spam, English only).
        • Results: Posts tab (each person with the sentence where they ask, highlighted), Jobs tab (table + why it passed), Filtered out (everything dropped, with the reason). Every result has a score 0–100 (clear ask, new post, decision maker) – Best first shows the strongest on top. Open list gives a plain list of names, companies and links; Export CSV downloads it.
        • Small CRM: give each prospect a status – New → Contacted → Replied → Meeting → Client (or Skipped) – add notes and a follow-up date; Follow-ups due lists who to contact today.
        • Send connection note on a post sends that person a note with one of your Message Types – through the same bot, limits and checks as a campaign, never twice to the same person.
        • Not a fit on a wrong result skips it and teaches its search: pick words from the author's headline (or the job title) and the search skips them from now on.
        • Keyboard: J / K next / previous, O open, C contacted, S skip, N note, B not a fit.
        • Every day by itself: Settings → Prospect finder → Run all ON searches every day at (e.g. 09:00). You get a Mac notification when it's done – and the list on Telegram if you add a bot token and chat id.
        • Global rules for all searches are in Settings → Prospect finder: blocked countries, target countries, daily limits, max experience. Upload CV creates searches from the skills in your CV.
        • The bot reads LinkedIn in the background (no scrolling, no window). A run with many searches takes a while – the bar on top shows Search 12 of 96, and the running search is marked ● Running now.

        If something looks wrong

        • Extension not connected – open Chrome, check the extension is ON, reload it once.
        • Many leads skipped with an error – Leads → Skipped tab → Retry error skips (top right).
        • Activity Log shows every step with the reason; page details for odd cases are saved in app/data/debug.
